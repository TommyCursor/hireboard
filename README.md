# HireBoard — Full-Stack Job Board Platform

A modern job board platform connecting employers and job seekers. Features job listings, applications, and employer dashboards. Built with Next.js 14, Supabase, and Framer Motion.

## Live Demo
[jobboard-pied.vercel.app](https://jobboard-pied.vercel.app)

## Features
- Job listings with search, filter by role, location, and salary
- Detailed job pages with company profiles
- Employer dashboard — post and manage job listings
- Job seeker profiles and application tracking
- Authentication for employers and applicants
- Smooth animations with Framer Motion

## Tech Stack
- **Frontend:** Next.js 14, TypeScript, Tailwind CSS, Framer Motion
- **Backend:** Supabase (PostgreSQL + Auth)
- **Deployment:** Vercel

## Getting Started
```bash
npm install
cp .env.example .env.local
npm run dev
```
